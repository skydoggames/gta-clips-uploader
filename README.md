# GTA Clips Uploader

The homepage, privacy policy and terms of service for GTA Clips Uploader. It's a personal tool that uploads the YouTube channel [Drivespace_GTA](https://www.youtube.com/@GTAdrivespace)'s own GTA 6 gameplay Shorts to YouTube.

- Homepage: https://skydoggames.github.io/gta-clips-uploader/
- Privacy policy: https://skydoggames.github.io/gta-clips-uploader/privacy.html
- Terms of service: https://skydoggames.github.io/gta-clips-uploader/terms.html

The tool itself runs only on the channel owner's PC. This repository only hosts these pages.
